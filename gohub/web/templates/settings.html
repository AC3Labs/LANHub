How updating works

  • LANHub downloads the new hub{{if $u.MediaUpdatable}} and LANHub Media{{end}} from the same published images docker compose pull uses, checks every download against its checksum, then restarts. The page is back in about ten seconds.
    • {{if $u.MediaUpdatable}}
  • LANHub Media switches over by itself the next time no video is playing.
    • {{else}}
  • LANHub Media can't be updated from here on this hub; update its image with docker compose pull.
    • {{end}}
  • If the new version doesn't start properly, LANHub goes back to the version in its image by itself.
  • The images' system files (security certificates, ffmpeg) only change when you pull new images: run docker compose pull && docker compose up -d now and then.
