LANHub is running, but isn't set up yet

This container couldn't find a valid APP_KEY in .env, and wasn't able to generate one automatically — this happens on some hosts where the bind-mounted .env file isn't writable from inside the container.

Fix it in two steps:

  1. Generate a key without starting the app: 
    docker compose run --rm hub php artisan key:generate --show
  2. Paste the result into your .env file as APP_KEY=base64:..., then restart: 
    docker compose up -d

Once APP_KEY is set, reload this page.
